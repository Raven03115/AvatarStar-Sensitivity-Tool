# 百變兵團靈敏度工具 v1.0

用於切換《百變兵團 / Avatar Star》的滑鼠靈敏度範圍，支援官方原版 **1~100** 與 **1~991** 之間切換。

## 使用風險

> **警告：**本工具的修改方式並未經《百變兵團 / Avatar Star》官方認可或授權。使用本工具可能違反遊戲官方規範，並存在帳號警告、限制、停權或封鎖等風險。是否使用請自行評估並承擔相關風險。

## 功能

- 自動偵測 `AvatarStar.pde` 與遊戲版本。
- 套用 **1~991** 靈敏度範圍。
- 還原官方 **1~100**。
- 靈敏度換算與倍率計算。
- 支援重新偵測與手動指定遊戲位置。
- 顯示目前 PDE 狀態、模式與修改相容性。
- 可匯出診斷資訊。
- 修改前建立備份；寫入失敗時會嘗試回復原始狀態。
- 無法唯一確認修改位置時拒絕寫入，不以固定檔案 Hash 或大小限制不同玩家版本。

## 使用方式

1. 將壓縮檔完整解壓縮到一般資料夾。
2. 雙擊 `啟動_百變兵團靈敏度工具.cmd`。
3. 等待工具偵測遊戲位置與 PDE 狀態。
4. 確認「修改相容性」為已支援後，再選擇：
   - `[1]` 套用 1~991
   - `[2]` 還原官方原版
5. 修改完成後再啟動遊戲。

## 選單

- `[1]` 套用 1~991
- `[2]` 還原官方原版
- `[3]` 靈敏度換算 / 公式
- `[4]` 重新偵測 / 手動指定位置
- `[5]` 詳細狀態
- `[6]` 匯出診斷
- `[0]` 離開

## 注意事項

- 修改時請先關閉遊戲。
- 不要在工具執行修改期間移動、取代或刪除 `AvatarStar.pde`。
- 若工具顯示不支援、未知或需要復原，請勿手動強制修改 PDE。
- 已於 Windows 11 本機與 Hyper-V 環境完成主要流程測試；Windows 10 尚未實測。
